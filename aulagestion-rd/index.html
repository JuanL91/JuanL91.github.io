Política de acceso

Configuración aplicada en esta versión.

Cuenta autorizada: la aplicación valida la identidad Google antes de cargar la base local.
Drive privado: el permiso drive.appdata continúa limitado al espacio privado de AulaGestión.
Token temporal: el token Google se conserva solo en la sesión del navegador y expira automáticamente.
GitHub Pages es público: el código de la aplicación puede ser consultado, pero el inicio de sesión no concede acceso a tus datos locales ni a tu Drive.
Administración de usuarios: para agregar otros docentes deben añadirse a la política de autorización y, mientras Google OAuth esté en modo Pruebas, también como usuarios de prueba en Google Cloud.

Acciones rápidas

Google Drive

Usa appDataFolder: AulaGestión no puede leer tu Drive completo.

AulaGestión usa este mismo cliente para el inicio de sesión y el respaldo privado en Drive.

Permiso solicitado: drive.appdata. La copia queda oculta dentro del espacio privado de la aplicación.

Microsoft OneDrive

Usa Apps/AulaGestión RD con el permiso AppFolder.

Permiso solicitado: Files.ReadWrite.AppFolder. Se usa OAuth 2.0 Authorization Code + PKCE, sin contraseña ni client secret.

Preferencias

Para conectar con la nube la app debe ejecutarse desde HTTPS o localhost; no funciona mediante file://. La gestión local sí funciona abriendo el archivo directamente.
